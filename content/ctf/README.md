# CTF challenge library — provenance

`public/data/ctf-challenges.json` contains **1,000 original training challenges** generated by `scripts/build_ctf_challenges.py`.

- All content is authored locally; nothing is copied from public CTF events.
- Distribution: Web 150, Crypto 120, Forensics 110, Misc 100, Reverse Engineering 90, Steganography 80, Pwn/Binary 80, Networking 70, OSINT 60, Mobile 50, Cloud 50, AI 40.
- Every challenge has a prompt, 2–3 hints, a flag, a step-by-step solution, a takeaway lesson, difficulty, points, estimated time and tags.
- Crypto/encoding challenges are **computed** in the generator (Caesar, Atbash, single-byte XOR, nested Base64, rail fence, Vigenère, hex, binary), so the published ciphertext, flag and solution are guaranteed consistent.
- All offensive tasks are framed for isolated local labs or explicitly fictional scenarios.

Regenerate with `npm run content:ctf`. Output is deterministic (fixed RNG seed).
