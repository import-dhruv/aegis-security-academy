# Chapter 29: 30 Practical Security Research Projects

> **Learning objectives.** Build a portfolio of progressively difficult tools and labs. Every project is designed for your own systems, authorized programs, or local labs.

> **Safety rule:** never point any project at systems you do not own or have explicit authorization to test.

## Project 1: HTTP Security Header Analyzer

- **Problem statement.** Inspect security headers of a site you own and identify missing or weak settings.
- **Learning objectives.** Parse HTTP responses; evaluate header presence and values; produce a report.
- **Prerequisites.** Python, requests, HTTP basics
- **Architecture.** CLI -> fetch -> header parser -> rule engine -> JSON/console output
- **Technology stack.** Python 3, requests, json
- **Implementation stages.** 1. Fetch URL 2. Parse headers 3. Define checks 4. Score each 5. Emit JSON
- **Testing methodology.** Run against your own lab server; verify each finding manually.
- **Security considerations.** Only scan owned hosts; no aggressive requests.
- **Expected outcome.** A reusable CLI that reports header posture.
- **GitHub portfolio recommendations.** README with sample output; include checks table; license and authorized-use note.
