# Chapter 30: 12-Month Cybersecurity Mastery Roadmap

> **Learning objectives.** Follow a realistic, adaptable 12-month curriculum with weekly objectives, daily study patterns, labs, programming, research, and measurable criteria.

> **Important:** this roadmap is an educational plan. Following it does **not** guarantee earnings, rewards, certifications, or employment. Adjust it to your life and pace.

## 30.1 Adapting to Your Weekly Time Budget

| Weekly hours | Daily pattern (approx.) | Strategy |
|---|---|---|
| **10 h/week** | ~1.5 h/day, 5 days | Focus on concepts + one lab per week. Skip optional reading; do core exercises only. Expect ~18 months for the same depth. |
| **15 h/week** | ~2 h/day, 5--6 days | The baseline used below. Complete all core labs and most projects. |
| **25 h/week** | ~3.5--4 h/day | Add extra labs, more CTFs, and 2--3 portfolio projects per month. Start public research earlier. |

**Daily study block template (2 h):** 20 min review of notes → 40 min reading/new concept → 45 min hands-on lab/code → 15 min journal and next steps.

## 30.2 Monthly Plans

### Month 1: Computer Science and Linux

**Weekly objectives**

- Week 1: number systems, bits/bytes, CPU and memory hierarchy (Ch2).
- Week 2: processes, threads, syscalls, user/kernel mode, stack/heap (Ch2).
- Week 3: Linux shell, permissions, users, processes, packages (Ch3).
- Week 4: Bash scripting, SSH, cron, logging; begin Python basics (Ch3, Ch5).

- **Concepts to master.** Chapters 1--3; *Computer Systems: A Programmer's Perspective* chapters 1--3.
- **Reading assignments.** MIT OpenCourseWare introductory CS; OverTheWire Bandit levels 0--10.
- **Courses / videos.** Linux man pages; Bash Guide; Python tutorial.
- **Practical labs.** Set up Ubuntu VM and Kali VM; practice 20 shell commands daily; complete Bandit levels 0--10.
- **Programming exercises.** Write 5 Bash scripts; begin Python exercises (variables, loops, functions).
- **Research assignments.** Keep a learning journal; document each command learned.
- **Revision test.** Explain binary/hex conversion; draw process memory layout; list 10 Linux commands from memory.
- **Measurable completion criteria.** Can navigate Linux fluently, explain CPU/memory concepts, and write simple scripts.

### Month 2: Networking

**Weekly objectives**

- Week 1: OSI/TCP-IP, Ethernet, MAC, IP, CIDR/subnetting (Ch4).
- Week 2: ARP, DNS, DHCP, ICMP; dig/traceroute (Ch4).
- Week 3: TCP/UDP, ports, sockets, HTTP; Wireshark/tcpdump (Ch4, Ch8).
- Week 4: TLS, proxies, NAT, firewalls; Nmap basics on lab network (Ch4).

- **Concepts to master.** Chapter 4; RFC 791/793/1034/9110 (skim); *Computer Networking: A Top-Down Approach* ch1--3.
- **Reading assignments.** Cisco Networking Academy intro; Wireshark user guide.
- **Courses / videos.** IETF RFC Editor; Wireshark docs; Nmap reference.
- **Practical labs.** Capture a TCP handshake; run `dig +trace`; scan your own lab VM with Nmap.
- **Programming exercises.** Write a Python DNS lookup tool and a URL parser (Ch5 projects 2--3).
- **Research assignments.** Map your home network; document IP scheme and devices.
- **Revision test.** Subnet 5 CIDR examples; explain TLS handshake; interpret a packet capture.
- **Measurable completion criteria.** Can subnet, explain TCP/DNS/HTTP, and analyze basic captures.

### Month 3: Programming and Web Development

**Weekly objectives**

- Week 1: Python data structures, functions, OOP, exceptions (Ch5).
- Week 2: regex, files, JSON, HTTP requests, sockets (Ch5).
- Week 3: HTML/CSS/JS, DOM, browser security model (Ch6).
- Week 4: backend, REST, SQL, databases, Node/Express basics (Ch7).

- **Concepts to master.** Chapters 5--7; Python docs; MDN web docs.
- **Reading assignments.** freeCodeCamp or MDN web tutorials; Python for Everybody (Coursera).
- **Courses / videos.** Python, MDN, PostgreSQL docs.
- **Practical labs.** Build the HTTP header analyzer, port scanner, and log analyzer (Ch5).
- **Programming exercises.** Create a Flask/Express CRUD app with SQLite/Postgres; add authentication.
- **Research assignments.** Write a blog post explaining SOP and CORS.
- **Revision test.** Write a regex, a class, an HTTP request with timeout, and a parameterized SQL query.
- **Measurable completion criteria.** Can build a small web app and explain client/server/data flow.

### Month 4: Web Security Foundations

**Weekly objectives**

- Week 1: web architecture, request lifecycle, security headers (Ch8).
- Week 2: OWASP Top 10:2025 categories A01--A05 (Ch9).
- Week 3: A06--A10; XSS, CSRF, SQLi, SSRF deep dives (Ch9).
- Week 4: Burp/ZAP workflows; certificate issues and auth failures (Ch9, Ch16).

- **Concepts to master.** Chapter 8--9; OWASP Top 10:2025; OWASP Web Testing Guide.
- **Reading assignments.** PortSwigger Web Security Academy (first 20 labs); OWASP Juice Shop walkthroughs.
- **Courses / videos.** OWASP, PortSwigger, MITRE CWE.
- **Practical labs.** PortSwigger labs: reflected/stored XSS, SQLi, CSRF; Juice Shop score 1-star.
- **Programming exercises.** Build the XSS and SQLi demonstration labs (Ch29 projects 14--15).
- **Research assignments.** Write notes on root cause and remediation for each lab solved.
- **Revision test.** Explain 10 vulnerability classes with root cause and fix; solve 20 labs.
- **Measurable completion criteria.** Can identify and explain common OWASP vulnerabilities; use Burp competently.

## 30.3 Quarterly Checkpoints

- **End of Q1 (months 1--3):** solid CS/Linux/network/programming foundation.
- **End of Q2 (months 4--6):** web and bug-bounty fundamentals; 30+ labs solved.
- **End of Q3 (months 7--9):** cloud, mobile, API, and advanced research skills.
- **End of Q4 (months 10--12):** AI security, professional practice, and a portfolio.

At each checkpoint: review your journal, re-take earlier revision tests, update your roadmap, and decide whether to adjust your pace or specialization.

## 30.4 Key Takeaways

- Consistency beats intensity; a modest daily block compounds.
- Each month has concepts, labs, code, research, and a measurable test.
- Adjust the schedule to 10/15/25 hours without changing the sequence.
- No timeline guarantees external outcomes.
